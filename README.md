# Multi-Step Form

## Overview

A fully responsive Stepper Form built with React, TypeScript, Tailwind CSS and React hook form, that took on challange from Frontendmentor.io website. It features a dynamic clickable stepper, real-time inline validation, and interactive plan/add-on selections, adapting seamlessly across mobile, tablet, and desktop screens.

## Features

- **Fully Responsive:** Optimized layouts for mobile, tablet, and desktop views.
- **Smart Stepper:** Clickable step navigation with built-in validation blocking (prevents skipping incomplete steps).
- **Inline Validation:** Robust, uncontrolled form validation using React Hook Form.
- **Dynamic Pricing:** Monthly/yearly billing toggle with automatic price and "months free" updates.
- **Interactive Summary:** Real-time add-on selection and total cost calculation.

## Technologies

- React
- TypeScript
- Tailwind CSS
- React Hook Form

## Learning

- Mastering uncontrolled components and validation with React Hook Form.
- Implementing complex state management and conditional logic using Context API.
- Building mobile-first, fully responsive UIs with Tailwind CSS.
- Designing intuitive UX flows (e.g., preventing invalid step jumps and handling final state lockouts).
